
# MAFIA — Multiplayer Web Game

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. افتح Terminal داخل المجلد.
3. شغّل:
   npm install
   npm start
4. افتح: http://localhost:3000

## اللعب من أجهزة مختلفة
ارفع المشروع على خدمة تدعم Node.js وWebSocket (مثل Render/Railway/Fly.io)، ثم شارك رابط الموقع مع اللاعبين.

## الموجود حالياً
- غرف خاصة بكود من 6 أحرف.
- حتى 16 لاعباً.
- Host يبدأ اللعبة.
- توزيع أدوار عشوائي عند البداية.
- بطاقات سرية لكل لاعب.
- Mafia / Old Man (الشايب) / Doctor / Citizens.
- مراحل الليل والنهار.
- تصويت وإقصاء.
- فحص فوز المافيا أو المواطنين.
- انتقال الهوست تلقائياً إذا خرج الهوست.

## ملاحظة
هذه نسخة MVP قابلة للتطوير. يمكن إضافة شات، قدرات ليلية فعلية للطبيب والمافيا، مؤقت، إعادة مباراة، نظام حسابات، أصوات ومؤثرات، ونظام أدوار أكثر تعقيداً.
